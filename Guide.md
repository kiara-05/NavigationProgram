## Introduction
This is the FAMU Campus Map Navigator! This program is designed to assist users in navigating FAMU’s campus. It provides walking directions between buildings, allows users to view available buildings, and ensures accurate route information. It is intended for anyone needing guidance to traverse the campus efficiently.

## Major Features
View Buildings
Quickly access a list of all the buildings available on campus. This feature ensures users can identify their starting and destination points.

Input Location and Destination
Enter your current location and desired destination. This feature provides detailed walking directions between the two points, helping you navigate efficiently.

Directions Feedback
Receive step-by-step walking directions. The program notifies you of invalid locations or destinations if the program cannot find a route.

Error Handling
The program validates user input to ensure only valid locations and destinations are accepted.

File Integration
All building data and route information are loaded from a CSV file. This ensures up-to-date and accurate information.


## How to Use the Program

## Start the Application

Run the FAMU Campus Map Navigator program from your terminal or development environment.

## Main Menu

Upon starting, you will see the main menu with the following options:

1.Enter your location and destination.

2.View all available buildings.

3.Exit.

## View Buildings

Select option 2 from the menu to display a list of all available buildings and their connections. This helps you confirm valid starting and destination points.

Input Location and Destination
1.Select option 1 from the menu.
2.Enter your current location when prompted.
3.Enter your desired destination when prompted.
4.If the route is valid, you will receive step-by-step walking directions.
5.If the route is invalid, the program will notify you.

## Exit
Choose option 3 from the menu to exit the program. Ensure your data is correctly loaded and validated before exiting for a smooth experience.
